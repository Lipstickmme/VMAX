VMAX MACHINE LTD - LOGO DROP FOLDER
===================================

  vmaxlogo.png        Wordmark for DARK backgrounds (white or yellow type).
                      Used in the site header and footer.
  vmaxlogo-black.png  Wordmark for LIGHT backgrounds (black type).
                      Used on the staff desk at /admin.

Accepted formats, best first: .webp  .avif  .png  .svg  .jpg
Until a file is here the site sets the VMAX wordmark in type instead, so
nothing looks broken while you are waiting on artwork.
