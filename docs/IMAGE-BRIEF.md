# Image brief

Every photograph the site is waiting for: 81 files in total, covering 50 machines across 17 classes, the page artwork and the logo.

Generated by `npm run gen:brief` from the site's own data, so it cannot fall behind the catalogue.

**Two ways to do the machines.** The 17 class files cover the whole catalogue on their own. A per-machine file overrides its class picture, so start with the classes and add the machines that matter most.

**Before you generate anything.** These are real machines from real makers. A generated picture of a Caterpillar 320 GC is not a Caterpillar 320 GC, and using one to sell a machine misrepresents the product and uses someone else's trademark. For anything customer-facing, ask the manufacturer or your distributor for press and dealer photography first: it is free, it is accurate, and it is licensed for exactly this. Generated images are a reasonable stand-in while you wait, and fine for the scene artwork, which is nobody's product.

Drop files into `public/assets/img/` (logos into `public/assets/brand/`). Any of `.webp`, `.avif`, `.jpg`, `.jpeg`, `.png` works and `.webp` wins when both exist.
